# Daniel Bakery | דניאל בייקרי

אתר קטלוג בעברית (RTL) למאפייה הבוטיקית של דניאל. React + TypeScript + Vite, ללא שרת/תשלום אונליין - הזמנות נשלחות כהודעת WhatsApp מוכנה מראש.

ראו `CLAUDE.md` לפירוט מלא של הפרויקט, ההחלטות וההגדרות.

## פיתוח

```bash
npm install
npm run dev
```

## בנייה

```bash
npm run build
npm run preview
```

## פריסה

הפריסה ל-GitHub Pages אוטומטית דרך `.github/workflows/deploy.yml` בכל push ל-`main`, לאחר הפעלת GitHub Pages (Settings → Pages → Source: GitHub Actions) בריפו.
